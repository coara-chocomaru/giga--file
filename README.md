# GigaFile の使い方

私のGigaFileは、Gigaファイル便 専用のwebviewアプリです。

## はじめに

- 対応端末：Android 9 以降
- インターネット接続が必要です。
- ファイルのアップロード・保管は Gigaファイル便 のサービスを利用します。
- Gigaファイル便の会員ユーザーには非対応です。

アプリを起動すると GigaFile のページが開きます。画面上部の右端にある「⋮」がメニューです。

## ファイルをアップロード

1. アプリを起動すると(アップロードページ)が開かれます
2. ページ内のファイル選択ボタンを押します。
3. Android のファイル選択画面が表示されたら、アップロードしたいファイルを選びます。
4. GigaFile の画面に戻り、アップロードを開始します。
5. アップロードが完了するまで、画面を閉じずに待ちます。
6. 完了後、URL などの情報が「アップロード履歴」に自動で記録されます。

## 通常 URL を使う

1. 画面右上の「⋮」を押します。
2. 「アップロード履歴」を開きます。
3. 送りたいファイルの履歴を探します。
4. 「URLをコピー」を押します。


### 短縮 URL を使う

アップロード履歴の「短縮URLコピー」を押すと、短縮 URL が生成され、クリップボードにコピーされます。生成済みの場合は、保存されている短縮 URL がコピーされます。

## QR コードを使う

アップロード履歴に「QRコード」が表示されている場合、その QR コードからアップロードファイル URL を開けます。

- QR コードをタップ：大きく表示します。
- 拡大画面の「画像を保存」：QR コード画像を保存します。
- 履歴の「QR画像を保存」：QR コード画像を保存します。

保存した画像は、端末の写真アプリなどから確認したり使用できます。保存先は通常 `Pictures/GigaFile` です。

## ファイルをダウンロード

※先にアプリ情報からデフォルトで開く→対応リンクで開く→許可に設定してください。

1. Gigaファイル便 の URL を開きます。別のアプリでリンクを開くアプリの選択が表示された場合は「GigaFile」を選んでください。
2. Gigaファイル便 のページが表示されたら、必要に応じてダウンロードKEYを入力します。
3. ページ内のダウンロード操作を行います。
4. ダウンロードが始まると、Android の通知欄に進行状況や完了通知が表示されます。
5. 保存されたファイルは、端末の「ダウンロード」フォルダー内にある `GigaFile` フォルダーから確認できます。

ダウンロードの状態は、アプリの「⋮」→「ダウンロード履歴」からも確認できます。

## 履歴の見方と操作

### アップロード履歴

アップロードしたファイルごとに、取得できた情報が表示されます。

- **URL**：アップロードファイルのURL です。
- **ダウンロード期限**：ファイルの公開期限
- **削除KEY**：Gigaファイル便 側でファイルを削除するときに使う情報です。
- **ダウンロードKEY**：ダウンロードに KEY が必要な場合に使います。
- **短縮URLコピー**：短縮 URL を生成、またはコピーします。
- **QRコード**：アップロードファイルURL の QR コードです。

各履歴にある操作

- **URLをコピー**：アップロードファイルURL をコピーします。
- **ページを開く**：そのファイルの アップロードファイルURLを開きます。
- **削除**：選択した履歴をアプリから削除します。
- **全件削除**：アップロード履歴をすべて削除します。

### ダウンロード履歴

ダウンロードしたファイルの名前、ダウンロード元 URL、状態、サイズ、日時を確認できます。

- **待機中**：ダウンロードの開始待ち、または再開待ちです。
- **ダウンロード中**：ファイルをダウンロードしています。
- **完了**：ダウンロードが完了しています。
- **失敗**：ダウンロードを完了できませんでした。通信状態や保存先の空き容量を確認して、もう一度お試しください。

「元URLをコピー」はダウンロード元 URL をコピーします。「削除」は履歴だけを削除します。「全件削除」はダウンロード履歴をすべて削除します。

## メニューについて

画面右上の「⋮」から、次の操作ができます。

| メニュー | 内容 |
| --- | --- |
| ホームに戻る | アップロードページに戻ります |
| アップロード履歴 | アップロードしたファイルの URL や KEY、QR コードを確認します。 |
| ダウンロード履歴 | ダウンロード状況を確認します。 |
| スクリーンショット | 現在画面に表示されている範囲を画像として保存します。 |

スクリーンショットの保存先は通常 `Pictures/GigaFile` です。ページ全体ではなく、画面に表示されている範囲が保存されます。

## 保存先

| 保存するもの | 保存先 |
| --- | --- |
| ダウンロードしたファイル | `ダウンロード/GigaFile` |
| QR コード画像 | `Pictures/GigaFile` |
| スクリーンショット | `Pictures/GigaFile` |
| アップロード・ダウンロード履歴 | アプリ内部 |

ファイルや画像を保存するときにストレージへのアクセス許可を求められることがあります。表示された場合は、保存するために許可してください。許可しない場合、その保存操作は完了できません。

## 困ったときは

**アップロード履歴にファイルが表示されない**

- アップロードで不具合が発生している
- 通信が不安定
どちらかの場合はアプリを再起動したりしてから試して下さい。

**ダウンロードが始まらない／待機中のままになる**

インターネット接続、端末の空き容量、Android の通知欄を確認してください。ダウンロードKEYが必要なファイルでは、正しい KEY を入力してください。

**ダウンロードページが開けない**

- 公開期限が切れている
- ファイルが削除済み
どちらかの可能性があります。

**短縮 URL を作れない**

- インターネット接続を確認
- アプリを再起動してから「短縮URLコピー」をもう一度押してください。

**QR コードが表示されない**

アップロード履歴に QR コードが表示されない場合、そのファイルの QR コード情報を取得できていない可能性があります。その場合は「URLをコピー」を使ってください。

## 注意事項

- アップロード履歴の「削除」や「全件削除」は、アプリ内の履歴を消す操作です。GigaFile 上にアップロードしたファイルは削除されません。
- ダウンロード履歴の「削除」や「全件削除」も、アプリ内の履歴を消す操作です。保存済みファイルそのものは削除されません。ダウンロード中の処理も、この操作だけでは取り消されません。
- アップロード履歴は最大 300 件まで保存されます。
- ファイルの保存期間、容量制限、ダウンロード可否などは Gigaファイル便 のサービス側の条件に従います。
